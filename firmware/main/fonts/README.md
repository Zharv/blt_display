`Montserrat-Medium.ttf` is the Montserrat typeface (Julieta Ulanovsky and contributors),
licensed under the SIL Open Font License 1.1. This copy comes from LVGL's
`scripts/built_in_font/`. It covers Latin, Ukrainian Cyrillic, °, ·, ×, Δ and −, and is
rendered at runtime by LVGL's Tiny TTF (see `../fonts.c`). Icons (LV_SYMBOL_*) fall back
to LVGL's built-in Montserrat bitmap fonts.
